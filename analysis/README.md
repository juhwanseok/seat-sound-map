> **저장소 배치 안내** — 이 문서는 원 작업 폴더 기준으로 쓰였다. 원래 `실험/` 폴더가 이 저장소의 `analysis/`이고, `02_제출물/web/`이 저장소 루트다. 스크립트는 `analysis/`에서 `python -I scripts/<이름>.py`로 실행한다. 원본 3D 데이터(`raw/`, 약 1.5GB)와 계산 중간 결과(`out/`)는 저장소에 넣지 않았다 — 아래 표의 주소에서 내려받아 `analysis/raw/<이름>/`에 풀면 된다. 기획서용 그림 스크립트는 넣지 않았다.

## v0 결과 (2026-11-09)
**검증된 것 (공개 수치와 대조)**
- 좌석 수: 추출 **1,194석** vs 공식 **1,184석** (+0.8%). 층별 분리는 높이 5m 기준이 거칠어 820/374 vs 공식 832/352 — 기준 보정 필요
- 무대 끝선~2층 최후열 수평거리: **24.5m** vs 공식 약 25m

**계산값 (검증 안 됨 — 가정에 좌우됨)**
- 객석 체적 약 10,600m³ (좌석당 8.9m³), 경계면적 약 2,940m², 객석 면적 468m²
- 잔향시간(500~1k Hz, Eyring) **2.0초**. 흡음률을 문헌 대푯값으로 넣은 결과다. 뮤지컬 전용극장 설계 의도("뮤지컬에 적합한 잔향")를 생각하면 실제는 더 짧을 가능성이 크다. **공개 실측값 없음.**
- 발코니 아래 1층 좌석 333석, 그중 D/H > 1이 199석, D/H > 2가 121석. **잠정값**: 슬래브 밑면을 점군 최저점으로 잡아 조명·난간이 섞일 수 있고, 맨 뒷줄 일부는 귀 높이가 슬래브와 비슷해 H가 비정상적으로 작다.

**v0에서 배운 것**
- Barron 수정이론은 잔향시간을 1.0~2.0초로 바꿔도 좌석 순위가 **완전히 같다**(스피어만 1.0). 이 모델에서 C80·G는 거리의 단조함수라 **좌석 순위 = 무대와의 거리 순위**일 뿐이다. 좌석 간 차이도 C80 기준 2.5dB 정도로 작다.
- → 거리만으로는 설명되지 않는 차이(측벽·천장 반사판의 초기 반사, 발코니 오버행의 차폐, 직접음 가림)를 보여 주려면 **형상 기반 계산(v1)** 이 있어야 한다. 이것이 서비스의 차별점이 된다.

## v1 — 형상 기반 레이 추적 (2026-11-09)
평면 단순화 + 이미지 소스 대신, **실측 점군을 그대로 쓰는 복셀 레이 추적**으로 바꿨다. 반사판·발코니·측벽을 손으로 고르지 않아도 되고, 실측 형상이 그대로 반영된다.

| 스크립트 | 하는 일 | 산출물 |
|---|---|---|
| `build_grid.py` | 점군 → 0.2m 점유 격자(팽창 1칸으로 틈 메움), 표면 법선, 객석 흡음 영역 | `out/grid.npz` |
| `raytrace_v1.py` | 레이 30만 개 0~200ms 추적(경면 + 산란 0.3), 좌석 귀 위치 반지름 1m 구 수음(유효 부피 보정), 해석적 직접음 + 가시선, 200ms 이후 지수 꼬리 → C80·D50·G·LF | `out/rt_v1_<tag>.npz/json` |
| `analyze_v1.py` | 시드 간 수렴, 흡음 가정 민감도, 거리 대비 추가 정보, 구역 비교, 좌석 지도 | `out/analysis_v1.json`, `out/seat_map_v1.png` |

조건: 1kHz 단일 대역, 음원은 무대 앞쪽 중앙(x −17, 높이 1.6m), **무확성(생음) 기준**. 벽 흡음률 0.08 / 0.15 / 0.25 세 시나리오, 객석 0.90. 1회 실행 약 35초.

**층별 좌석 수 — 공식 수치와 정확히 일치**
- 2층 **352석** = 공식 352석
- 1층 **820석** = 공식 832석(휠체어석 12석 포함) − 휠체어석 12석
- 설계 모델(GLB)의 1층 맨 뒤 22석은 점군상 바로 위 0.15m에 발코니 밑면이 있어 사람이 앉을 수 없는 위치다 → 설계 모델과 실측 불일치로 보고 **제외**. 처음 v1 실행에서 이 22석이 G −18dB 같은 극단값을 냈던 원인이다.

**신뢰성 점검**
| 점검 | 결과 | 해석 |
|---|---|---|
| 시드 1 vs 2 (같은 조건) | 순위 상관 G 0.99, D50 0.93, LF 0.93, C80 0.86. C80 좌석별 차이 중앙값 0.36dB | C80이 가장 시끄럽다. 최종본은 시드 4개 이상 평균 |
| 벽 흡음률 0.08·0.25 vs 0.15 | 순위 상관 **0.98~0.998** (네 지표 모두) | 흡음률을 몰라도 **좌석 순위는 거의 그대로**. 서비스는 순위·상대 등급으로 보여 준다 |
| 잔향시간(추적 결과 감쇠율) | 1.1초(α 0.25) ~ 1.4초(0.15) ~ 1.9초(0.08) | 절대값은 가정에 좌우. 표시하지 않거나 범위로만 |
| 거리와의 순위 상관 | C80 0.16, D50 0.23, G 0.89, LF −0.68 | v0(통계 모델)은 1.0이었다. **명료도는 거리로 설명되지 않는다** → 형상 계산의 가치 |
| 거리로 설명 안 되는 C80 변동 | 잔차 표준편차 0.95dB vs 시드 잡음 0.28dB | 신호가 잡음의 약 3배 |

**드러난 패턴 (같은 거리 22~28m 비교)**
- 1층 **발코니 아래**(200석): C80 3.7dB, G −0.7dB → **또렷하지만 작고 건조하다**(위쪽 잔향이 차단됨). 발코니 아래 좌석의 고전적 특성과 방향이 맞다
- **2층**(214석): C80 2.0dB, G +0.5dB → 더 크고 울림이 많다
- 1층 중간 열(x −34~−28, 발코니 앞)은 1층에서 C80이 가장 낮다
- 공간감(LF)은 무대에서 멀수록, 2층 뒤·측면 블록에서 높다

**한계**: 무확성 생음 기준이다(뮤지컬은 실제로 스피커 확성). 1kHz만. 흡음률·산란계수는 가정. 관객 머리와 바로 앞 등받이는 가시선에서 빼서 좌석 꺼짐(seat dip) 효과가 없다. 실측 임펄스응답 검증 없음.

**가정 (모두 `raytrace_v2.py`의 `BAND`, `SRC`)**
- 흡음률 객석 0.72 / 0.90 / 0.85, 벽 0.20 / 0.15 / 0.12 (250 / 1k / 4kHz), 산란 0.2 / 0.3 / 0.5
- 생음: 무대 앞 중앙 배우 1명(무지향)
- 확성: 프로시니엄 좌·우 끝(높이 6m) 메인 2개 + 상단 중앙(7.5m) 센터 1개, 객석 중심 조준, 에너지 지향 패턴 ((1+cosθ)/2)^q, q = 1 / 3 / 5. **이 홀의 실제 스피커 배치는 공개 자료가 없다.** 발코니 아래 보강(딜레이) 스피커는 넣지 않았다
- 프로시니엄 개구부(점군 측정): 폭 약 20m(z −13.8~6.4), 중앙 높이 약 8m

**결과**
| 항목 | 생음 | 확성(가정) |
|---|---|---|
| 잔향(추적 감쇠율) | 1.41 / 1.45 / 1.39초 | 초기 감쇠 0.81 / 0.86 / 0.92초 (지향 스피커가 흡음성 객석을 먼저 때림) |
| C80 1kHz 중앙값 (10~90%) | 2.9dB (1.8~4.3) | 6.5dB (5.4~8.1) |
