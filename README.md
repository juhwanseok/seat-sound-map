# 객석 소리지도 — 우리금융아트홀

올림픽공원 공연장 3D 실측 공공데이터로 계산한 좌석별 소리 비교. 예매 전에 자리마다 얼마나 또렷하고, 크고, 감싸는지 지도와 미리듣기로 확인한다.

2026년도 한국체육산업개발(주) 공공데이터 활용 경진대회 출품 시연본이며, 기관의 공식 서비스가 아니다.

시연 영상(1분, 소리 포함): [demo.mp4](https://juhwanseok.github.io/seat-sound-map/demo.mp4) — 공개된 화면을 `analysis/scripts/record_demo.py`로 자동 조작해 녹화했다(자막과 커서 표시는 녹화할 때만 덧붙인 것).

## 실행
빌드 단계·서버·외부 라이브러리·API 키가 없다. 정적 호스팅(GitHub Pages 등)에 이 폴더를 그대로 올리면 된다.
로컬에서는 이 폴더에서:

```
python -m http.server 8765
```

브라우저로 `http://localhost:8765` 를 연다. (`index.html`을 파일로 직접 열면 브라우저 보안 정책 때문에 스타일·스크립트가 막힐 수 있다.)

공유 주소: `#m=pa|natural & k=TOT|D50|C80|G|LF & f=1|2 & s=<좌석 번호>` — 예: `#m=pa&k=D50&f=1&s=307` (`pa` 스피커 확성이 기본, `natural`은 무대 육성)

## 파일
| 파일 | 내용 |
|---|---|
| `index.html`, `style.css`, `app.js` | 화면 (좌석 지도, 지표 전환, 좌석 상세, 소리 도착 그래프, 미리듣기, 두 자리 비교) |
| `data/seats.js` | 좌석 1,172석의 위치·층·지표(ISO 3382-1 D50, C80, G, LF)·공연장 내 백분위 |
| `data/env.js` | 좌석별 반사 에너지 포락선(2ms × 100칸 × 3대역 × 2모드, 0.5dB 단위). 브라우저에서 임펄스응답을 합성하는 데 쓴다 |
| `data/dry.js` | 미리듣기 원음(박수·피아노풍 아르페지오) — 직접 합성한 음원이라 저작권 제약이 없다 |

데이터 파일은 `analysis/scripts/build_web_data.py`가 만든다. 계산 과정·검증 결과는 [`analysis/README.md`](analysis/README.md)에 있다.

## 사용한 공공데이터
- 한국체육산업개발(주) 「올림픽공원 공연장 실감형 콘텐츠」 — 공공데이터포털 15127487 (우리금융아트홀 GLB 3D 모델, E57 점군)

## 한계
- 실측 음향 자료가 없어 흡음률을 일반적인 값으로 가정했다. 숫자보다 좌석 간 상대 비교로 봐야 한다(흡음 가정을 바꿔도 좌석 순위 상관 0.97 이상).
- 기본 지도는 스피커 확성 기준이다(2025년 이 공연장 공연 기간의 98%가 뮤지컬). 스피커 구성은 기관 대관 자료에 공개된 음향장비 목록(센터 12, 발코니 아래 4, 사이드필 4, 프런트필 6)을 따랐지만, 목록에 설치 위치가 없어 위치·방향·출력 비율·지연은 가정했다. 스피커 배치 가정은 흡음 가정보다 결과에 영향이 크다 — 2층에 보조 스피커가 있다고 가정하면 2층 좌석 순위가 올라간다([`analysis/layout_sensitivity.json`](analysis/layout_sensitivity.json)).
- 관객·등받이·무대 세트, 시야는 계산에 없다.
